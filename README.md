# CODSOFT Task 1 - Movie Genre Classification

## Project Description

This project predicts the genre of a movie based on its plot or description using machine learning and natural language processing.

## Technologies Used

- Python
- Pandas
- Scikit-learn
- Matplotlib
- TF-IDF
- Logistic Regression

## Dataset

The project uses movie plot descriptions containing movie titles, genres, and descriptions.

## Machine Learning Process

1. Data loading
2. Data preprocessing
3. Text feature extraction using TF-IDF
4. Train-test split
5. Model training
6. Model evaluation
7. Movie genre prediction

## Model

Logistic Regression was used to classify movies into different genres.

## Output

The trained model predicts the genre of a movie based on the plot provided by the user.
